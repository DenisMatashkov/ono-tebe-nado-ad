# Оно тебе надо

Ссылка на репозиторий: https://github.com/DenisMatashkov/ono-tebe-nado-ad

Учебная вёрстка страницы аукциона по предоставленным скриншотам и инструкции. Используются HTML и CSS, локальные изображения и шрифты. Ширина страницы — 1100 px, как в заготовке.

## Как открыть проект

1. Распакуйте архив целиком.
2. Откройте папку `ono-tebe-nado-ad`.
3. Дважды нажмите на `index.html`: страница откроется в браузере.

Live Server, установка пакетов и подключение к интернету для отображения страницы не нужны. Папки `fonts`, `images` и `styles` должны оставаться рядом с `index.html`.

## Файлы проекта

| Файл или папка | Назначение |
| --- | --- |
| `index.html` | Семантическая разметка и весь текст страницы |
| `styles/global.css` | Исходный сброс отступов, `box-sizing`, ширина страницы и общие правила |
| `styles/style.css` | Расположение блоков, размеры, типографика, фоны и оверлеи |
| `fonts/fonts.css` | Подключение локальных начертаний Raleway |
| `fonts/*.woff`, `fonts/*.woff2` | Файлы шрифта обычного и жирного начертания |
| `images/` | Фотографии, логотипы и значки социальных сетей |
| `.github/workflows/tests.yml` | Сохранённая конфигурация проверки из заготовки |

В HTML и CSS добавлены краткие комментарии к основным частям страницы.

## Анализ макета

### Основные блоки

1. **Шапка**: горизонтальное меню, чёрный логотип по центру страницы, контактные данные справа.
2. **Обложка**: фоновая картина с затемнением, единый заголовок «Оно тебе надо» в три строки, описание и кнопка «Сделать ставку».
3. **Лоты**: заголовок, три карточки со ссылками и ссылка «посмотреть больше».
4. **Об аукционе**: белый логотип в чёрном круге слева, заголовок и два абзаца справа.
5. **Подвал**: контактные данные, вертикальное меню и три ссылки на социальные сети.

В `main` находятся ровно три секции: `cover`, `lots` и `about`.

### Повторяющиеся элементы

| Элемент | Где встречается | Как переиспользуется |
| --- | --- | --- |
| Контактные данные | Шапка и подвал | Общий класс `address`; `header__address` задаёт положение и ширину в шапке |
| Затемнение | Обложка и каждая карточка | Общий класс `overlay` |
| Карточка | Фильм, книга, картина | Общие классы `card`, `card__title`, `card__text`; модификаторы меняют только фон |
| Ссылки меню | Шапка и подвал | Одинаковые подписи и переходы; общие правила подчёркивания и активной ссылки |
| Логотип аукциона | Шапка и блок об аукционе | Готовые SVG в чёрном и белом вариантах |

### Цвета и типографика

| Свойство | Значение |
| --- | --- |
| Фон страницы и светлый текст | Белый, `#fff` |
| Основной текст и круг логотипа | Чёрный, `#000` |
| Оверлей | Чёрный с непрозрачностью 60%, `rgb(0 0 0 / 60%)` |
| Шрифт | Raleway, резервный — `sans-serif` |
| Начертания | Обычное, 400; жирное, 700 |
| Заголовок обложки | 100 px, межбуквенный интервал 30 px |
| Заголовки секций | 40 px, жирное начертание |
| Заголовки карточек | 22 px, жирное начертание, подчёркивание |
| Основной текст | 20 px, межстрочный интервал 24 px |
| Навигация и адрес | 18 px |

Верхний регистр заголовков, описания обложки и кнопки задаётся через `text-transform: uppercase`.

### Изображения

- **Для оформления**: `cover.jpg` и `card-lot-01.jpg`, `card-lot-02.jpg`, `card-lot-03.jpg`. По условию они подключены как фон через CSS; содержание лотов передано заголовками и текстами.
- **Для передачи информации**: `logo-black.svg`, `logo-white.svg`, `yt.svg`, `vk.svg`, `pinterest.svg`. Подключены через `img` с альтернативными подписями.

### Особенности, требующие внимания

- Кружочки между пунктами верхнего меню — маркеры списка `list-style: circle`; у первого пункта маркер убран.
- Логотип в шапке центрируется относительно всей страницы: сетка `1fr min-content 1fr` сохраняет его положение при разной ширине меню и адреса.
- Три слова обложки находятся внутри одного `h1`, каждая строка имеет своё выравнивание.
- У последней буквы каждой строки сброшен `letter-spacing`, чтобы справа не появлялся лишний интервал.
- Описание обложки имеет увеличенные промежутки между словами через `word-spacing`.
- Оверлей находится под текстом благодаря `position` и `z-index`.
- Тексты в карточках прижаты к нижней части, заголовки — к верхней. Минимальная высота позволяет карточкам расти при добавлении содержимого.
- Список карточек использует `flex-wrap`: дополнительные карточки переходят на новую строку с тем же промежутком.
- Левая колонка блока «Об аукционе» имеет ширину карточки — 334 px. Размер круга — 240 × 240 px.
- Абсолютное позиционирование используется только для оверлея; общая раскладка построена на Grid и Flexbox.

## Что было в заготовке

- В `index.html` уже были `lang="ru"`, кодировка UTF-8, viewport и корректный заголовок страницы. Тело документа было пустым, CSS ещё не подключался.
- В `global.css` были заданы ширина `body` 1100 px, центрирование страницы, семейство Raleway, сброс отступов, наследование цвета ссылок, ширина изображений и шрифт кнопок. Файл сохранён без изменений.
- `style.css` содержал только комментарий-заготовку.
- Все необходимые изображения и оба начертания Raleway уже присутствовали. В `fonts/fonts.css` шрифты подключались через `@font-face` в форматах WOFF2 и WOFF.

## Поведение страницы

Пункты меню «посмотреть лоты» и «об аукционе» переходят к секциям страницы. Телефон и почта используют `tel:` и `mailto:`. Значки социальных сетей ведут на соответствующие сервисы.

Кнопка «Сделать ставку», ссылки карточек и ссылка «посмотреть больше» оформлены по макету. Формы приёма ставок и дополнительные страницы в задании не предусмотрены, поэтому их обработчики не добавлены.

Адаптация под телефон не требуется на этом этапе: исходная фиксированная ширина страницы сохранена.

## Проверка готовой работы

Страница проверена в Chromium при открытии через `file://`, без локального сервера:

- CSS подключается в порядке «шрифты → глобальные стили → локальные стили»; изображения и оба начертания шрифта загружаются без ошибок.
- В документе один `h1` и три секции внутри `main`; пункты меню переходят к нужным секциям.
- Шапка имеет высоту 293 px; секция лотов — 1052 × 723 px; блок «Об аукционе» — 1052 × 595 px; подвал начинается на отметке 2848 px и имеет высоту 180 px. Эти размеры соответствуют подписям на скриншотах.
- При временном добавлении четвёртой карточки она переносится на следующую строку; ширина 334 px и промежуток 25 px сохраняются.
- При временном увеличении текста карточка растёт по высоте, текст остаётся внутри. Проверочные изменения в итоговую страницу не включены.
